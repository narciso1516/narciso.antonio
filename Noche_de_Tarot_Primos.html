Lectura sin iniciar

Guía para ti, el lector

1. Mira la posición. Primero interpreta qué papel juega esa carta dentro de la tirada: pasado, reto, consejo, futuro, etc.
2. Une las cartas. No leas cada una como una frase aislada. Busca continuidad: ¿qué cambia?, ¿qué se repite?, ¿qué tensión aparece?
3. Haz preguntas. En vez de afirmar algo inevitable, prueba con: “¿Esto te recuerda a alguien?”, “¿Dónde sientes este bloqueo?”, “¿Qué opción estás evitando?”
4. Cierra con una síntesis. Resume la lectura en una idea y una acción concreta para reflexionar.
