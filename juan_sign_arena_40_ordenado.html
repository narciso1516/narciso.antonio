📘 The Sign Rules

Same signs (addition): Add the absolute values and keep the shared sign.
Example: -3 - 2 = -5.

Different signs (addition): Subtract absolute values; keep the sign of the number with the greater absolute value.
Example: -9 + 4 = -5.

Subtraction: Subtracting a number means adding its opposite.
Example: 6 - (-2) = 8.

Like terms: Combine only terms with the same letters and powers.
Example: 3x + 2x = 5x, but 3x + 2y cannot be combined.
